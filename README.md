# dotnet-artisan

**让你的 AI 编码代理真正精通 .NET。** 即装即用，零配置。

Grok优化版：插件正常运行，支持MCP工具集成，帮助项目学习新的知识。

## Grok 集成优化

- 支持 xAI Grok 的工具调用 (bash, GitHub MCP, file ops)
- 增强 sandbox 环境下的 .NET 命令执行
- 自动学习新 .NET 特性到 skills/references
- 插件运行检查：hooks 兼容性
